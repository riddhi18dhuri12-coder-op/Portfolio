01 about

Curious by default, hands-on by habit

I like the LAMP stack for how quickly it turns into something real, I like Java for how it makes you think in structure, and I like data because it's the part of a system that tells the truth.

I'm a computer engineering student at Datta Meghe College of Engineering, Navi Mumbai, graduating in 2027. Over the last couple of years I've moved through a handful of internships that each pulled me into a different corner of tech — building a database-driven website from scratch, writing Java applications with JDBC, and digging into SQL for real data analysis work.
